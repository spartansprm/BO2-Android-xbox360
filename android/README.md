# Android

Consulta [README.md](../README.md) para preparar las herramientas, generar los programas y compilar el APK.

`app/` contiene el lanzador y los controles táctiles, `game/` la integración nativa, `runtime/` el SDK y `recomp/` los módulos generados.

Los avisos de las dependencias están en [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
