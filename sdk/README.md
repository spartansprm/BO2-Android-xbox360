# ReXGlue SDK

SDK basado en ReXGlue 0.10.0, revisión `c94f5ebdcb3c9d1a460ca48e04f9758448f8d518`.

Los encabezados están en `include/`, la implementación en `src/` y las plantillas del generador en `resources/templates/`.

La compilación descarga las dependencias públicas fijadas en `tools/android_runtime_deps.json` y `tools/android_vulkan_deps.json`, conservando los archivos versionados de `thirdparty/`.
